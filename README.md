Proyecto Web - PlayComp (IA Gaming)

Aclaracion sobre el repositorio

En un principio, creamos el proyecto en un repositorio a traves de la terminal y despues lo juntamos al repositorio de nuestro proyecto general de programacion. 

Sin embargo, como el requisito de la entrega era mandar un enlace directo a GitHub exclusivamente para la web, decidimos pasar todo el codigo a este repositorio nuevo para que no haya lios con la correccion. 

Por este motivo, los primeros cambios de Xabier y de Valentina no se ven como tal en los commits de este repositorio, pero en la documentacion del proyecto esta evidenciado como Valentina crea el repositorio inicial por consola y el resto del trabajo.

Reparto del trabajo

Para que quede constancia de lo que ha hecho cada uno, el trabajo se ha dividido asi:

- Xabier: Se encargo de pensar y crear toda la estructura general del proyecto. Definio las paginas necesarias y empezo a desarrollar la pagina principal (index.html).
- Valentina: Se encargo de toda la parte visual. Hizo el archivo CSS, metio las imagenes y mejoro bastante el aspecto y distribucion de la pagina principal.
- Ares:  Ha hecho la pagina de  informacion y su correspondiente pagina de css, explicando como funciona la IA y estructurando su pagina correspondiente.
- Asier: Ha hecho toda la parte de la pagina de suscripciones.
